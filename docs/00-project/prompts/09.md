# 09 — Full Completion Audit

## Goal
Verify that every scope item from prompts `01.md`–`08.md` was actually completed, with real supporting tests — not just that each prompt was run once. This is a verification pass, not new feature work.

## Blueprint Reference
§8 (Testing — RBAC), §9 (Implementation Order), §10 (Explicitly Out of Scope).

## How to work

Do **not** treat this as a single task through the `plan-council-code-test` loop — it's an audit with a checklist, followed by targeted fix-tasks (each of which *does* go through the full loop) for anything found incomplete.

### Step A — Rebuild the checklist from source, not from memory

For each prompt `01.md` through `08.md`, re-read its **Scope** section and turn every bullet into a concrete, checkable claim:

- Does the file/class/migration/route/page named in the scope actually exist?
- Does `docs/00-project/plans/` contain an approved plan covering it? A scope item with no corresponding plan on record is a gap even if the code exists — the loop was bypassed.
- Are there Pest tests specifically exercising this scope item?
- For anything UI-facing: a corresponding Pest v4 browser test, and, where the item involves non-trivial client-side logic, a Vitest component test?
- For anything role-gated: an RBAC test proving the wrong role is denied?
- **Confirm nothing multi-tenancy-related crept back in** — no `tenant_id` column, no tenant-scoping middleware, no `super_admin` role, no impersonation flow. Blueprint §10 explicitly deferred these; their presence would itself be a finding.

### Step B — Run the full suite and reconcile

Run `php artisan test` and `npm run test`. Cross-reference failures, skips, and gaps against the checklist from Step A.

### Step C — Report findings

Produce a table: prompt number → scope item → implemented? (Y/N) → plan on record? (Y/N) → test coverage? (Y/N) → notes.

### Step D — Close the gaps

For every gap found, run it through the **full** `plan-council-code-test` loop (Step 0 through Step 7), council review included.

### Step E — Re-run Step B

After all gaps are closed, re-run both suites once more to confirm everything is green together.

## Documentation

- Write the completion checklist (Step C) and its final, post-fix state to `docs/03-daily-logs/`.
- Backfill any missing ADRs to `docs/00-project/architecture-decisions/`.
- If any gap reveals a plan that was skipped entirely, note this explicitly in the daily log.

## Update CLAUDE.md

Confirm every section still marked with a placeholder comment has actually been filled in.

## On completion

Report a final summary: total scope items audited, gaps found, gaps closed, confirmation both test suites are green, and explicit confirmation that no multi-tenancy scaffolding was reintroduced. This is the last prompt in the sequence — there is no next file.
