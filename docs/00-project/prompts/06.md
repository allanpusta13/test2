# 06 — Customer Ordering Page

## Goal
Build the public ordering flow as React/Inertia pages: menu, cart, checkout, order tracking.

## Blueprint Reference
§5 (Customer Ordering Page), §9 step 6.

## Scope
- The site root renders `Pages/Public/Menu.tsx` directly — no separate landing screen, no tenant subdomain (this is just `/` now).
- `Menu.tsx` — category tabs, item browsing, "Add to Cart" with a shadcn dialog for modifier selection.
- `Cart.tsx` — cart state management, session-backed on the server side.
- Checkout — a shadcn form posting via Inertia's form helpers to an idempotent, rate-limited checkout endpoint (client-generated idempotency key). Fulfilment note fixed as "Pay at counter."
- `OrderTracking.tsx` — real-time status updates via the signed-token channel from prompt 03.

## How to work

Also add Vitest coverage for cart-specific logic (quantity stepper, modifier price calculation) that's easier to verify in isolation.
