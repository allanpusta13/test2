# 05 — Super Admin Panel

## Goal
Build the Super Admin Filament panel, scoped strictly to Tenants, Users, and Roles/Permissions.

## Blueprint Reference
§4.1–§4.2 (Super Admin Panel, Impersonation Audit Log), §11 step 5.

## Scope
- `TenantResource` — create/edit tenants, `is_active` suspend toggle.
- `UserResource` — create/edit users across all tenants, assign tenant + role.
- `RoleResource` — read/assign only, no create/delete for roles themselves.
- Impersonation flow requiring a `reason`, logged to `impersonation_logs`, with an active-impersonation banner shown in the Tenant Panel.

## How to work
Use the `plan-council-code-test` skill. Explicitly check in the council review that no billing/subscription/feature-flag/global-report functionality is creeping in — §4.1 scopes this panel deliberately narrow, and it's an easy place for scope creep to sneak back in unnoticed.

## Documentation (via Tolaria MCP)
- If the council flags and removes any out-of-scope addition during review, note it briefly in `docs/03-daily-logs/` as a reminder of the scope boundary for future work on this panel.
