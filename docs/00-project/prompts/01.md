# 01 — Project Setup

## Goal
Scaffold the Laravel/Filament project per the finalized blueprint's tech stack.

## Blueprint Reference
§2 (Tech Stack), §11 step 1.

## Scope
- Laravel 13 (confirm PHP 8.3+ available).
- Filament 5.x with Livewire 4 + Tailwind v4.
- Laravel Reverb + a queue driver.
- Pest installed as the test runner (with Pest v4 browser testing plugin).

## How to work
Use the `plan-council-code-test` skill for this task. Even setup work goes through plan → council → code → full Pest suite, since dependency/version choices made here are hard to unwind later.

## Documentation (via Tolaria MCP)
- If any version/tooling decision has real trade-offs (e.g. Postgres vs MySQL, queue driver choice), write an ADR to `docs/00-project/architecture-decisions/`.
- If you had to look up current Laravel 13 / Filament 5 / Livewire 4 specifics, save what you learned to `docs/02-research/`.

## Update CLAUDE.md
Record the confirmed stack versions and any setup gotchas (e.g. Tailwind v4 requirement) under a "Stack" section.

## On completion
Confirm `php artisan test` runs (even with zero tests) and the app boots locally. Proceed to `docs/00-project/prompts/02.md`.
