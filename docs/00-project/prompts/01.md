# 01 — Project Setup

## Goal
Scaffold the Laravel + Inertia + React + shadcn project per the v4 blueprint's tech stack.

## Blueprint Reference
§2 (Tech Stack), §9 step 1.

## Scope
- Laravel 13 (confirm PHP 8.3+/8.4 available).
- Inertia.js server-side adapter + `@inertiajs/react` client-side.
- React 19, TypeScript, Vite.
- shadcn/ui initialized on Tailwind v4.
- Laravel Reverb + `laravel-echo` client setup + a queue driver.
- Pest installed as the backend test runner (with Pest v4 browser testing plugin).
- Vitest + React Testing Library installed for frontend component tests.
- No Filament, no Livewire, no multi-tenancy package of any kind — this is a single-restaurant system, see blueprint §10.
