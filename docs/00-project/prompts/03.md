# 03 — Database Migrations & Models

## Goal
Build out the full schema from the blueprint and the corresponding Eloquent models.

## Blueprint Reference
§3.2 (Database Schema), §11 step 3.

## Scope
- All tables from §3.2: tenants, users, roles, permissions, role_permission, categories, menu_items, modifiers/modifier_options, orders, order_items, tax_rates, inventory_items, inventory_transactions, menu_item_inventory, payments, impersonation_logs.
- Seeders for the fixed/global `roles` and `permissions` tables (§3.2 — these are seeded once, never tenant-editable).
- Models with correct relationships, and `BelongsToTenant` applied to every tenant-scoped model per §02.

## How to work
Use the `plan-council-code-test` skill. Split this into multiple small tasks (e.g. one task per related table group) rather than one giant migration task — this keeps each council review and test run meaningful.
