# 02 — Multi-Tenancy Foundation

## Goal
Implement tenant resolution and the cross-tenant isolation test suite, before any tenant-scoped resource exists.

## Blueprint Reference
§3 (Multi-Tenancy), §10 (Cross-Tenant Isolation Testing), §11 step 2.

## Scope
- `IdentifyTenant` middleware (subdomain resolution).
- `BelongsToTenant` trait + global scope, applied to every tenant-scoped model as models are introduced.
- Filament `HasTenants` support on the `User` model, resolved from the same middleware.
- The cross-tenant isolation test suite itself (§10: scope test, broadcast channel test, direct-ID access test) — written now even though there's little to scope-test yet, so every later resource is tested against it as it's added.

## How to work
Use the `plan-council-code-test` skill. The council's security/multi-tenancy reviewer is doing the real work on this task — do not let it rubber-stamp the plan.
